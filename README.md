## Ответы на вопросы
1. > В чём разница между полем класса и обычной переменной в функции?

Поля класса доступны всем методам класса, в отличии от переменной, которая доступна только внутри тела функции, где была объявлена.

2. > Что такое конструктор и зачем он нужен?

Конструктор - функция внутри класса, которая используется для инициализации полей.

3. > Зачем нужен `@override` перед `toString()`? Что будет если его убрать?

`@override` используется для переопределения функции родительского класса и проверяет, есть ли такая функция в родительском классе. Если его убрать, то код выполнется корректно, но не защитит от опечаток в названии функции.

4. > Чем статическое поле `static int _counter` отличается от обычного поля? Сколько копий этого поля существует в программе?

Обычное поле пренадлежит каждому отдельному объекту, а статическое всему классу целиком. В программе всегда существует только одна копия этого поля, вне зависимости от того, сколько объектов было создано. 

5. > Что означает нижнее подчёркивание в `_counter`?

Нижнее подчёркивание делает переменную приватной для файла, то есть переменная становится недоступной из других файлов.
